# Portfolio — Soumia Lahnini

Version autonome en HTML, CSS et JavaScript. Elle ne demande aucune installation de dépendances. Les sept captures des vrais sites sont optimisées en WebP dans `images/`.

## Ouvrir dans Visual Studio Code

Décompressez cette archive et ouvrez le dossier dans VS Code. Pour tester toutes les pages localement, lancez `python -m http.server 8000` depuis le dossier et ouvrez `http://localhost:8000`. Le formulaire de contact prépare un message WhatsApp, sans enregistrer les informations saisies.

## Publier sur GitHub Pages

1. Créez un dépôt GitHub et placez **tout le contenu** de ce dossier à sa racine : `index.html`, `contact.html`, `styles.css`, `script.js`, `contact.js`, `favicon.svg`, `images/` et `README.md`.
2. Dans le dépôt, ouvrez **Settings → Pages**.
3. Sélectionnez **Deploy from a branch**, branche `main`, dossier `/(root)`, puis enregistrez.
4. GitHub Pages donnera l’URL publique après son déploiement.

Les chemins des fichiers sont relatifs et fonctionnent aussi sur une URL GitHub Pages qui contient le nom du dépôt. Les témoignages sont volontairement présentés comme en attente de vrais avis et d’autorisation de publication. Remplacez ce texte uniquement par des retours authentiques.
